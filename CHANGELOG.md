# Changelog

## 2.0.0 — 2026-07-31

- Replaced the monolithic research handbook with a modular plugin.
- Added explicit research task DAGs with fake-edge and cycle validation.
- Added a persistent claim-evidence graph with provenance and contradiction preservation.
- Added resumable run state and immutable completion.
- Added bounded specialist agents and one-writer artifact ownership.
- Added source-quality scoring and prompt-injection defenses.
- Added deterministic report, citation, graph, and completion audits.
- Added schemas, evaluation fixtures, hooks, tests, and a sealed release workflow.
- Incorporated ontology-first and task-graph concepts from `codejunkie99/graph-engineering` under MIT attribution.
