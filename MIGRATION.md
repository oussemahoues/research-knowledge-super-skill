# Migration from the monolithic super-skill

Version 2 replaces the former single-file research handbook with an executable plugin architecture.

## Removed from the control plane

- Platform comparison essays
- Generic statistical and visualization tutorials
- SEO and brainstorming workflows
- Hard-coded tool names from unrelated hosts
- Monolithic prompts combining acquisition, extraction, analysis, and synthesis

## Retained as operational concepts

- Claims registry
- Source provenance
- Confidence and uncertainty labels
- Contradiction tracking
- Research briefs and completion checks

These concepts now live in typed schemas, focused skills, deterministic libraries, and audit gates. The original version remains recoverable from repository history.
